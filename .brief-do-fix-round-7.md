## B2 (P0) — the listing page budget counts characters, not bytes

`listFilesPage` budgets with SQLite `LENGTH(content)`, which counts **characters**. Emoji and
other astral-plane text are 4 UTF-8 bytes per character, so an 8MiB budget admits ~32MiB of
real payload. `PAGE_ROW_OVERHEAD_BYTES = 256` also under-counts: each row emits its path
**twice** (`_id` and `path`), plus a 64-char `contentHash` and a UUID `deviceId`.

Measured through the real route:
```
20 x 524k emoji, short paths    -> 33,537,984 B  200 (16 KB under the ceiling)
17 x 524k emoji, 1000-char paths -> 500 {"error":"Internal error."}
   + Uncaught (in promise) Serialized RPC ... limited to 32MiB ... 33572012 bytes
```
That is the exact failure P0-2 was assigned, on the exact route, with the exact signature.

**Fix:** budget on real UTF-8 bytes (`LENGTH(CAST(content AS BLOB))` or equivalent) and charge
per-row overhead from **actual field lengths** (path counted twice, hash, deviceId, JSON
envelope), not a flat constant. Prove with astral-plane content at maximum path length that no
response approaches the ceiling and no input yields a 500 or an unhandled rejection. Apply the
same fix to the asset listing.

## Smaller items

**M1 — `label` on `POST /api/device/register` is uncapped.** A 3MB `label` reaches SQLite and
throws `SQLITE_TOOBIG`; it is caught, so no unhandled rejection, but it returns
`500 code:UNKNOWN` — a terminal refusal the client classes as transient and retries forever.
`assertFieldSize` covers `deviceId` only, while `MAX_FIELD_BYTES`'s own docstring claims it
covers "any single scalar RPC field that lands in SQLite". Cap `label`; then **check that
docstring's claim against every scalar field that reaches SQLite** and fix any others.

**L1 — two new Biome format regressions you introduced:**
`apps/www/worker/durableObject/assets.ts` and `apps/www/worker/routes/devices.ts` pass
`biome format` at HEAD and fail now. Fix exactly those two. Leave the 7 pre-existing HEAD
failures alone.

**L2 — `since` is unvalidated.** `GET /api/files?since=abc` → `Number("abc")` = NaN → binds
NULL → **200 with zero files, silently**. Not reachable from the current client, but give it
the same validation the cursor now has.

**L4 — `listAssetsForGc()` is the last unpaginated RPC.** `SELECT * FROM assets`, unbounded,
returned whole. Rows are small so it needs a large asset count to bite, but it is the same
shape as the bug you just fixed. Bound it.
